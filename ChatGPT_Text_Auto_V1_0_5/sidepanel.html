1. Prompt ảnh — một dòng một ảnh

Dán hoặc chọn file TXT. CHAR_XX / BG_XX trong dòng là tên ảnh tham chiếu. Có một trong hai, hoặc không có, vẫn tạo được. Số lần gửi phụ thuộc ô “Số prompt mỗi lần gửi”.

2. Yêu cầu chung — tùy chọn

Có chữ thì tool ghép vào cuối mỗi lần gửi. Để trống thì chỉ gửi đúng các dòng prompt đã chọn.

3. Số prompt mỗi lần gửi

Mỗi lần gửi vào ô chat ChatGPT có thể gồm nhiều dòng prompt. Tối đa 10. Để 1 thì mỗi ảnh một dòng như cũ.

4. Thư mục ảnh tham chiếu

Chọn thư mục chứa CHAR_01.png, BG_02.jpg… Tên file khớp mã trong prompt. Thiếu ảnh thì vẫn gửi dòng đó.
