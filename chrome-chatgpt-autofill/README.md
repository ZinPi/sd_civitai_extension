# ChatGPT auto điền

Chỉ làm một việc: điền văn bản vào ô chat [ChatGPT](https://chatgpt.com) và gửi.

Không gồm quy tắc CHAR/BG, không gọi API TeamSocLo/OpenAI, không đụng Automatic1111.

## Cài vào Chrome

1. Mở `chrome://extensions`
2. Bật **Developer mode**
3. **Load unpacked** → chọn thư mục `chrome-chatgpt-autofill`
4. Mở https://chatgpt.com và đăng nhập
5. Bấm icon extension, dán văn bản, giữ tick **Gửi tự động**, bấm **Điền và chạy**

Nếu chưa có tab ChatGPT, extension tự mở tab mới rồi điền.
